# Nivara Technologies Website

This is the repository for the Nivara Technologies website, built with React, TypeScript, Tailwind CSS, and Vite.

## Project Structure

- `frontend/` - Contains the React + TypeScript frontend application.
  - `src/` - Application source code.
  - `package.json` - Frontend dependencies and scripts.
  - `vite.config.ts` - Vite configuration.

## Getting Started

Follow the steps below to set up and run the project locally.

### Prerequisites

Make sure you have Node.js and npm installed on your machine:
- **Node.js**: `v18.x` or higher (recommended)
- **npm**: `v9.x` or higher

### Installation

1. Navigate to the `frontend` directory:
   ```bash
   cd frontend
   ```

2. Install the project dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the local development server, run:
```bash
npm run dev
# or
npm start
```

Once the server starts, you can view the application in your browser at:
* Local: [http://localhost:3000](http://localhost:3000)
* Network: `http://<your-local-ip>:3000`

### Available Scripts

In the `frontend` directory, you can run the following scripts:

- `npm run dev` / `npm start`: Starts the development server with Hot Module Replacement (HMR).
- `npm run build`: Compiles and bundles the application for production into the `dist/` folder.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Runs TypeScript compiler type checking without emitting output files.
- `npm run clean`: Cleans up the build output folder (`dist`).

## Tech Stack
- **Frontend Framework**: React 19
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS 4
- **Language**: TypeScript
- **Animations**: Motion
- **Icons**: Lucide React
